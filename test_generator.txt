tạo quan hệ CALL với node có calls khác rỗng. ví dụ:
"calls": [
        "QuizServiceImpl.getQuizStatsById",
      ],
thì tạo quan hệ CALL với node có class_name = QuizServiceImpl và method_name = getQuizStatsById

tạo quan hệ CALLED_BY với node có called_by khác rỗng, ví dụ:
"called_by": [
        "JwtProvider.generateAccessToken"
      ],
thì tạo tạoquan hệ CALLED_BY với node có class_name = JwtProvider và method_name = generateAccessToken

tương tự với implements tạo quan hệ IMPLEMENT, implemented_by thì tạo quan hệ implemented_by

        "UserPrincipal"
      ],
